\section{Experiments}

\paragraph{Setup.}
SAM\,3 proposals are organised into a containment tree (stability-ordered, cap 256 nodes, IoU-dedup 0.9).
A Qwen3-VL-4B selector emits a \texttt{<SEL>} token whose embedding scores tree nodes.
\textbf{V2}: frozen MLLM, 10k images.
\textbf{S1}: frozen MLLM, multi-source, 20k steps.
\textbf{S2}: LoRA ($r{=}16$) + trainable \texttt{<SEL>}, from V2 or S1 init.
\textbf{S2 long}: S1 init, 12k steps on PACO + Pascal-Part + gRefCOCO.
Chains are answered top-down: \emph{flat} searches all nodes, \emph{tree} restricts the part search to the selected object's subtree.
For editing, the selected mask drives Qwen-Image-Edit (masked blend) or FLUX.1-Fill; quality is judged by Qwen2.5-VL-72B (VIEScore protocol).
